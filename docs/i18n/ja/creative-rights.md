# クリエイティブの権利、クレジット、そしてあなたの手元に残るもの

他の人が作った優れた作品を、ライセンスの専門家にならなくても、そして作った人たちをひそかに置き去りにすることもなく、使えるべきです。そのためLollyは、利用するすべての作品の出所を保持し、それに対して記録されたライセンスを読み取り、そのライセンスがあなたの実際の利用に何を求めているかを判断し、プログラムにできる部分を行い、あなたにしかできない部分を明示します。

これはいずれも法的助言ではなく、あなたのプロジェクトについての判定でもありません。Lollyは事実を記録し、ライセンスそのものの法的文書から読み取った少数のルールを適用し、その過程を示します。条件付きのライセンスは、通常の、許可された選択です。それが壊れたアセットとして提示されることは決してありません。

## 分けて保たれる3つの事実

「CC BY 4.0」「この利用にはクレジットが必要です」「クレジットはあなたが今ダウンロードしたファイルの中にあります」は3つの異なる主張であり、Lollyはこれらを分けて保ちます。

- **証拠** は、ソースが宣言した内容であり、見つかった時点のまま、誰がそう述べたか、どこで読み取られたかとともに記録されます。後からのインポートが以前の記録を上書きすることは決してありません。
- **義務** は、レビュー済みのルールが、その証拠を1つの利用、1つの配信経路、1つのオーディエンスについてどう解釈するかです。共有に関する条件は、あなたが非公開で作業している間は条件付きのままです。
- **配信** は、完成したバイト列が実際に運ぶものであり、読み返すことで測定されます。Lollyは、読み手が配信済みのファイルの中にクレジットを見つけた後にのみ、クレジットが含まれていると述べます。

## 最初にこれに出会う場面

絵文字セットは日常的な事例です。Twemojiは CC BY 4.0 なので、絵文字を含む見出しは、アートワークがクレジットされた状態で書き出され、あなたがすることは何も残りません。OpenMojiの2つのセットはいずれも CC BY-SA 4.0 なので、そのグリフの1つをブランド処理で再着色することは翻案にあたり、その翻案を共有するには、一度だけ互換性のあるライセンスを選ぶ必要があります。セットの選択自体が妨げられることは決してなく、セットのコントロールには、選択した箇所にライセンス名が示されます。同じルールが、カタログのイラスト、LUT、フォント、その他の記録済みの作品にも当てはまります。

## Lollyが使う言葉

エクスポートパネル、Verify、コマンドライン、そして機械可読な結果に共通する、1つの語彙です。

| 表示される内容 | 意味すること |
|---|---|
| Source credits に含まれます。 | クレジットは準備済みで、その配信経路はそれを運べる状態にあります。まだ何も書き込まれていないため、これは成功を知らせるメッセージではありません。 |
| このファイルのメタデータにクレジットが含まれています。 | 配信されたバイト列が読み返され、クレデンシャルが検証され、必要なすべてのソースがその中に見つかりました。 |
| クレジットとクレデンシャルはダウンロードパッケージの中にあります。 | クレジットは、成果物と並ぶ同梱ファイルとして運ばれます。人に渡すときは、それらを一緒に保管してください。 |
| この投稿の説明にこのクレジットを追加してください。 | 選んだ配信経路はクレデンシャルも読み取れるクレジットも運ばないため、クレジットの文言を貼り付けるのはあなたの役目です。 |
| この翻案を共有する場合、互換性のあるライセンスが必要です。 | ShareAlikeのソースが変更され、その結果は非公開利用以外の場所に向かおうとしています。選択は1回の操作であり、配置ごとのダイアログではありません。 |
| ソースのライセンスが記録されていません。 | このソースについては何も記録されていません。これは埋めるべき欠落であり、その作品に対する不利な判定ではありません。 |
| 条件は記録済みですが、まだ解釈されていません。 | 識別子は認識され、その条件は一覧化されていますが、ここにあるルールはそれらを解釈しません。自動的な合格判定も、自動的な禁止もありません。 |
| 2つのライセンス宣言が一致していません。 | 2つの記録が異なるライセンスを示しており、どちらの許諾が適用されるかはまだ選ばれていません。 |
| 記録されているCC0の権利放棄のもとでは、必須のクレジットはありません。 | その権利放棄は何も求めません。それでも、儀礼的なクレジットは提示されます。 |
| クレジットは、配信されたファイルの中にありません。 | クレジットは約束されていましたが、読み返しではそれが見つからず、ファイルは依然としてあなたのものです。再度書き出すか、クレジットの文言を手動で使用してください。 |

Lollyは「著作権確認済み」「法的に安全」「完全にクリア」「権利処理済み」という言葉を使いません。また、製品内のどこにも単一の緑色のライセンスバッジは存在しません。これらの言葉は、どんなプログラムにも確認できないことを主張してしまうからです。

### 記録はされるが、解釈はされない

CC BY-NC、CC BY-ND、およびNC-SAとNC-NDの組み合わせは認識され、その条件は一覧化されますが、ここにあるルールはそれらを解釈しません。これらは条件を明示する行とともに `licence.unknown` を報告します。商用の文脈は、価格やアカウントから読み取れるものではなく、組み合わされたそれぞれの文書は、ルールが手を付ける前に個別のレビューを必要とします。

さらに3つの、正直な回答があります。いずれも許可を意味するものではありません。

- `LicenseRef-` 識別子は、そのまま返されます。これは保存済みの定義を指し示すものであり、綴りだけでプロプライエタリと判断されることは決してありません。
- 何にも認識されない宣言は、未解析のまま返され、元の文言がその横に保持されます。
- `A OR B` は権利者が提示した選択であるため、すべての選択肢が返され、どれも選択されません。`A AND B` は累積的であり、これらのルールは2つのプロファイルを合わせて読み取るのではなく、それをそのまま記録します。

ライセンス情報がないことが、その作品を自由に受け渡してよいという証拠として読み取られることは決してありません。

## Lollyがあなたのために行うこと

- **カタログでは。** 作品のシートには、そのソースと制作者、正規化されたライセンス名(その下に元のラベルも保持)、記録がある場合はコピー可能なクレジット、そして利用が何を求めるかを述べる1行が表示されます。タイルは要件を示すだけで、書き出しが完了したと主張することは決してありません。
- **エクスポートパネルでは。** レンダリングが記録済みの作品を使用すると、Source credits カードが表示されます。これは状態、Details の裏にあるクレジット文言、Copy credit ボタン、そして判断が必要なときのインラインカードを示します。判断がブロッキングのダイアログになることは決してありません。操作が残っているダウンロードはそのまま進み、非公開の作品は引き続き利用できます。
- **ファイルの中では。** 記録済みの作品を配置した書き出しは、区別できる作品ごとに1つの Content Credentials ソースイングリディエントを書き込み、それを公開アドレスにある元のバイト列に紐づけ、制作者、ライセンスとそのリンク、ソース、リビジョン、変更内容を運びます。Lollyは自らが観測したことに署名します。上流のアーティストに代わって主張に署名することは決してなく、Verify はそのどちらが起きたかを示します。
- **書き込み後は。** 配信されたバイト列は、クレジットが含まれると何かが述べる前に読み返されます。検証に失敗したクレデンシャルは、届けられたクレジットとして数えられません。
- **編集可能な `.lolly` ファイルでは。** バイト列は、レビュー済みのライセンスがソースの受け渡しを許可すると記録している場合にのみ運ばれ、パックの `CREDITS.txt` には、何が運ばれたか、どのライセンスのもとでか、そして何が理由とともに差し控えられたかが一覧化されます。記録のないライセンスは差し控えられます。差し控えられたコンテンツを意図的に含めることもでき、その場合はクレジットファイルにそれがあなたの選択であったことが記録されます。
- **Verify では。** Sources パネルには、ファイルが記録するすべてのソースが、算出済みの要約、クレジット、Copy credit ボタン、要求時にのみ開かれる Open source リンク、そして検査内容の明示された限界とともに一覧表示されます。Check for this use の質問は、利用方法を選んだときにのみ尋ねられ、それに答えるために何かが取得されることはありません。
- **メタデータを削除するときは。** 除去処理は、そのファイルがもう運ばなくなるソースクレジットの数を伝え、クレジットの文言を提示し、クレジットを添えたクリーンなファイルを提供します。除去済みのバイト列が再スタンプされることは決してありません。

## あなたの手元に残るもの

- **あなたのライセンス選択は、あなたのものです。** ファイルの権利を主張することは、かつては1つだった3つの状態を分けます。公開ライセンスが宣言されていない状態、明示的な全著作権留保の表示、そして実際の公開ライセンス許諾です。Lollyが権利の行を書き込むのは後者の2つに対してのみであり、あなたのプロフィールから書き込むことは決してありません。
- **あなたの作品が、あなたの代わりに再ライセンスされることはありません。** ソースの条件と、あなた自身の出力宣言は、別々の記録です。ShareAlike の条件は、それが対象とする翻案には適用されますが、あなたが作った他のすべてに自動的に適用されることはありません。
- **非公開の作品は、引き続き利用できます。** 共有に適用される条件は、共有が視野に入ったときに提起されます。ここでの何かがインポートの禁止に転じることはなく、あなた自身のファイルとの間にライセンスに関する質問票が立ちはだかることもありません。
- **判断は、それ自体の事実に対して記憶されます。** 記録したすべての選択には、それが対象とした作品、利用方法、経路、オーディエンスの指紋が刻まれます。セット、処理、フォーマット、オーディエンスのいずれかを変更すると、その質問は再び尋ねられます。「ライセンスを無視する」という一括スイッチは存在しません。警告をクリックして消しても、クレジットを届けたり許可を与えたりすることはできないからです。
- **あなたの詳細情報は、第三者のクレジットとは切り離されたままです。** あなた自身の個人メタデータを削除しても、クレジットされたアーティストが消えることはなく、必須のクレジットが、あなたの連絡先情報を書き出す口実になることは決してありません。

## コマンドラインでは

レンダリングは、評価に必須のクレジットまたは問題がある場合、標準エラー出力に `Rights:` ブロックを出力します。これには、状態、`code - summary` の形式で問題ごとに1行、配信されたファイルが読み返された結果、そして貼り付け用のクレジット文言が含まれます。

```
Rights: actions-required
  licence.adaptation-choice - If you share this adaptation, it needs a compatible licence.
  Credential intact. It records 1 source. The exporter recorded it; the source did not sign a credential of its own.
  Credits included in this file's metadata.
  "water wave (OpenMoji Color 17.0.0)" by Vanessa Boutzikoudi (OpenMoji), CC BY-SA 4.0 https://creativecommons.org/licenses/by-sa/4.0/, source https://raw.githubusercontent.com/hfg-gmuend/openmoji/f9fc506a3f913be9897ab0181d611d4c910a4104/color/svg/1F30A.svg, changes: recoloured.
```

この2つの主張は独立しており、それこそが両者を分けて保つ理由です。クレジットはファイルの中にあり、そしてファイルを共有する前に、まだライセンスに関する判断が必要です。ファイルはどちらの場合でも書き出されます。

| 状態 | 意味 | 終了コード |
|---|---|---|
| `ready` | 人の判断を待っているものは何もありません。 | 0 |
| `actions-required` | ファイルを共有する前に、まだ判断が残っています。ファイルはそのまま書き出されます。 | 4 |
| `use-not-covered` | レビュー済みのルールが、このライセンスはこの利用をカバーしないと示しています。 | 4 |
| `unknown` | 唯一の問題は欠落です。記録されなかったライセンス、または解釈されない条件です。 | 0 |
| `delivery-failed` | 評価によってではなく、受領記録によって設定されます。約束されていたクレジットが、配信されたバイト列の中に見つからなかったことを示します。エクスポートパネルはこれを表示し、CLIは代わりに読み返しの行で同じ事実を報告します。 | 出力されません |

終了コード4は、このCLIがすでに「不可」と判定した保護チェックに与えているコードです。これは意図的に3ではありません。3は「別のランナーで再試行する」ことを意味し、ライセンスに関する判断は、どのランナーで実行しても待ち受けているからです。

`--rights=private` は、このレンダリングが誰にも配信されないことを表明します。ブロックはそれでも出力され、クレジットもコピーできる状態のままです。取り下げられるのは共有に適用される条件であり、配信の主張は一切記録されません。条件を無視するためのフラグは存在しません。`--rights=ignore` は使用エラーです。

問題コードは安定しており、機械可読であり、翻訳された文言とは独立しています。

`attribution.source-missing`, `attribution.delivery-missing`, `licence.adaptation-choice`, `licence.use-not-covered`, `licence.grant-conflict`, `licence.unknown`, `source.redistribution-unknown`, `credential.ingredient-missing`.

MCP経由では、`lolly_verify` が、要約、記録済みのソースごとの1行、そして明示された検査の限界を含む `rights` ペイロードを返します。ブラウザ不要の `lolly_render` は、`status`、`issues`、`credits`、`fingerprint`、そしてバイト列を読み返すことで測定される `creditsInFile` フラグを返します。

## ルールの置き場所

4つのエンジンモジュールがあり、いずれも純粋です。ネットワークも、時計も、ファイルシステムも使いません。ルールデータはバージョン管理され、リポジトリの中にあり、取得されることは決してありません。

| モジュール | 内容 |
|---|---|
| `engine/src/rights-profiles.ts` | 識別子テーブル、最小限のSPDX式リーダー、出典を伴うレビュー済みプロファイル、そしてクレジットが出力しうるリンクについての唯一のルールです。 |
| `engine/src/rights-evaluate.ts` | 分類、問題、著作者表示の計画、そして指紋です。決定論的であり、同じ事実であれば順序が異なっても同じ答えになります。 |
| `engine/src/rights-attribution.ts` | 読み取り可能なクレジット、同梱ファイル、ソースイングリディエント、そして書き込み後に測定される受領記録です。 |
| `engine/src/rights-report.ts` | 検証済みのクレデンシャルを、Verify が尋ねる3つの質問として読み返したものです。 |

`tests/fixtures/rights/` にある期待値ファイルは、評価器の出力からではなく、ライセンス文書そのものから作成されており、そのREADMEは各期待値の根拠となる条項を引用しています。

## これが行わないこと

率直に述べます。名指しされない欠落は、約束として読まれてしまうからです。

- **NCとNDは解釈されません。** それらの条件は記録され、unknown として報告されます。
- **配信先は確認されません。** Lollyはキャプションを準備しますが、コネクタがリクエストを受け付けたからといって、クレジットが読み手に届いた証拠にはなりません。また、後のアップロード、スクリーンショット、トランスコードが隠しメタデータを保持することを、ここでの何かが約束することもありません。
- **ネイティブなメタデータのクレジット欄は、計画から書き込まれません。** クレジットは Content Credentials と、読み取り可能なテキストの中を運ばれます。IPTCおよびXMPのソースごとのクレジット欄は、まだ著作者表示の計画からは埋められません。
- **訂正と撤回は実装されていません。** 記録済みの作品に、欠落している制作者やローカルな訂正を追加すること、また記録を撤回することには、まだインターフェースがありません。
- **連携プロバイダーは実装されていません。** 購入済みのストック素材、独自の許諾、プロバイダーのアカウントには取り込み経路がなく、それらの許諾はあなた自身の陳述としてのみ記録できます。
- **組織のポリシーはこれらの結果と組み合わされません。** エクスポートポリシーとライセンス条件は現在のところ別のものであり、組織の承認は権利者からの許可ではありません。
- **一部の配信経路は、まだこの仕組みに乗っていません。** カタログの原本のダウンロード、一括ZIP、派生ダウンロード、Send、Copy image は、まだこれらのクレジットを評価も運搬もしません。
