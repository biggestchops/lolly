## Default Permission

Allows the app to open the system sign-in sheet with `authenticate`.

#### This default permission set includes the following:

- `allow-authenticate`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`lolly-auth:allow-authenticate`

</td>
<td>

</td>
</tr>

<tr>

</td>
